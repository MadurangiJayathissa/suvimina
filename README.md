# MindCare Psychologist Website

A responsive multi-page frontend starter built with HTML, CSS and vanilla JavaScript.

## Pages
- index.html — home, hero, doctor introduction, appointment CTA, one YouTube embed, 8-image gallery, footer
- about.html — profile, education, experience and services
- appointment.html — appointment request form
- contact.html — contact details, map placeholder and enquiry form

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize before publishing
1. Replace `Akila Aushada Bandara` and all sample contact details.
2. Replace the sample profile images with approved doctor/clinic photos.
3. Replace the YouTube video ID with the doctor's chosen video.
4. Replace the Google Maps embed with the clinic's correct location.
5. Review education, registrations, experience and services with the psychologist.
6. Connect forms to a secure backend before collecting real patient information.

## Important privacy note
The forms currently show a demo confirmation only. They do not transmit or store submissions. Do not collect sensitive mental-health information through an unsecured form. Use secure hosting, access controls, data minimization and appropriate consent/privacy notices before launch.
